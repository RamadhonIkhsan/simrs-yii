# Project Instructions

## Anti-Slop Guidelines
This project enforces **antislop** (Anti Slop: Rules for AI Coding Agents). It is a quality filter to prevent generic AI slop in generated code, UI, copywriting, and documentation.

- **Core Filter:** Always apply clean, purposeful architecture without bloated AI templates or empty commentary.
- **Code Hygiene:** No generic AI comments (e.g., `// This function adds two numbers`), keep only essential domain explanations.
- **No Boilerplate Comments:** Jangan menambahkan docblock boilerplate seperti `/** {@inheritdoc} */`, endpoint/route annotations, atau komentar deskripsi method yang jelas dari kodenya.
- **Craftsmanship:** Every design and architectural decision must have an articulable purpose.
